# Scenario 8: Which Requests Does Biome-for-Nx Guidance Apply To

## User Prompt

Three requests arrive. (a) Add Biome to an Nx workspace with three small libraries, and the requester suggests a `biome.json` in each library. (b) A repository whose README says ESLint and Prettier are the mandated standard asks for a Biome setup. (c) A plain Node script repository with no Nx asks for Biome tasks integrated with workspace caching. For each, say whether this guidance applies and what you would do.
