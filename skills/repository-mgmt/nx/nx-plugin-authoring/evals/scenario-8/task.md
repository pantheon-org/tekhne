# Scenario 8: Plan a new organisation plugin from scratch and test it

## User Prompt

Your team wants a new Nx plugin that scaffolds service libraries with a README. Write the step-by-step plan for creating it, from zero to a validated first generator, including how the file templates work and how the plugin is tested before anyone uses it. Keep the first release to one generator.

## Repo state

- An existing Nx workspace with no custom plugin.
- The team will later add more generators, so the design should not force a rewrite.
