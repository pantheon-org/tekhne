# Scenario 5: Requests the Extractor Cannot or Should Not Handle

## User Prompt

The user says: "I have three jobs. One: `article.xml` is a JATS XML version of a paper and I want its results table as CSV. Two: for a different paper I only need the title, abstract, DOI resolution and current citation count. Three: `poster.pdf` is a low-resolution scan with no embedded text, and I want its kinetics data; I think my MATHPIX_APP_ID is set but I never set MATHPIX_APP_KEY."

Repo state: the environment has MATHPIX_APP_ID but not MATHPIX_APP_KEY.
