# Scenario 5: Routing Between Semantic Scholar, PubMed and Google Scholar

## User Prompt

The user asks for three things in one message:

1. "Find recent randomised controlled trials on statin use in elderly patients for a clinical review."
2. "Find patents and grey literature that mention solid-state battery electrolytes."
3. "Find papers on retrieval-augmented generation." Both `google-scholar-search` and this skill are installed, and a `semantic-scholar` MCP server is configured in the session.

Decide which tool to use for each request and explain why.
