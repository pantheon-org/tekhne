# Scenario 04: Vendor/Contractor Friction

## User Prompt

"Our contracted integration vendor keeps missing the agreed API delivery dates and pushing back on scope. I need to raise this in tomorrow's vendor sync — any framing that would help?"

## Expected Behavior

1. Recognize this as a vendor/contractor-relations trigger and load `references/contractor-relations.md` only.
2. Select 1-3 aphorisms that genuinely fit contractor friction and delivery-date slippage, not a generic "working with people" lesson.
3. Attribute the citation to Jerry Madden / NASA LLIS #1956.
4. Apply the aphorism explicitly to the vendor-sync framing task described, not as a floating, generic quote.
5. Keep the citation brief — a line or two applied to the situation, not the full contractor-relations category.

## Success Criteria

- Only `references/contractor-relations.md` is loaded; no other category file is referenced.
- 1-3 aphorisms are cited, not the full category list.
- The citation names Madden and/or LLIS #1956.
- The response ties the aphorism to the specific vendor-sync framing need, not stated generically.

## Failure Conditions

- A different category (e.g. Managing Project Staff) is loaded instead of Contractor Relations.
- The full contractor-relations list is pasted into the response.
- No attribution to Madden or LLIS #1956.
- The response drafts the vendor-sync talking points itself without connecting them to a cited aphorism at all, missing the point of the skill.
